Android + GitHub Actions

Tu idea, en movimiento.

Crea videos de texto animado con tres estilos y sonido, sin PC ni API de pago. Al enviar la solicitud, GitHub hace el renderizado.

GitHub abrirá una solicitud prellenada. Toca Submit new issue para comenzar el renderizado. El contenido de la solicitud será público si el repositorio es público; no incluyas secretos. Solo las solicitudes de la cuenta propietaria activan el renderizado.

La vista es ilustrativa; el MP4 final se renderiza en GitHub Actions a 24 fps, con cuatro escenas.

¿Dónde descargo el MP4?

Después de enviar el issue, abre su enlace a la ejecución de GitHub Actions y descarga el archivo motion-studio-mp4 en Artifacts. También puedes ejecutar el workflow manualmente desde la pestaña Actions.
